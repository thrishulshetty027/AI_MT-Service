    ```python
    import json
    import logging
    from typing import Dict, List, Any

    logger = logging.getLogger(__name__)

    def fill_gaps(scenarios_json: Any, type_map: Dict, function_signatures: List[Dict]) -> Any:
        """
        Add missing null_ptr, boundary, and normal scenarios deterministically.

        Args:
            scenarios_json: Parsed JSON from Stage 2A (dict with 'scenarios' list)
            type_map: Parsed JSON from Stage 1B (dict with 'functions' key)
            function_signatures: List of function signature dicts from context assembler

        Returns:
            Updated scenarios_json with gap-fill scenarios added
        """
    ```

    Implementation rules:
    - Accept scenarios_json as either a dict (already parsed) or a string (parse with json.loads)
    - Build a dict tracking what each function already covers: `{func_name: set(test_type values already present)}`
    - For each function in function_signatures:
      - If function has NO "NORMAL" scenario → add one: `{function_name, scenario_id: auto-generated, scenario_name: "Normal operation", test_type: "NORMAL", intent: "Verify normal operation with valid inputs", branch_targeted: null, expected_behavior: "Returns expected value for valid inputs"}`
      - For each parameter of that function (from type_map functions → params):
        - If param is_pointer is True AND function has no "NULL_PTR" scenario → add: `{function_name, test_type: "NULL_PTR", intent: "Verify NULL_PTR handling for {param_name}"}`
        - If param is a numeric type (uint, int, float) AND function has no "BOUNDARY_MIN" → add BOUNDARY_MIN scenario for that param
        - If param is a numeric type AND function has no "BOUNDARY_MAX" → add BOUNDARY_MAX scenario for that param
    - Auto-generate scenario_ids as "S_GAP_{N:03d}" where N increments from the max existing scenario_id number
    - Log each gap added at INFO level
    - Return the modified scenarios_json dict

    - Check: test_type values are valid TestType enum values
    - Check: scenario_ids are unique
    - Return list of error strings (empty = valid)

    **2. `src/value_sanitizer.py`** — Deterministic C literal suffix correction (per S1-09):

    ```python
    import re
    import logging
    from typing import Dict, Any, Optional

    logger = logging.getLogger(__name__)

    def sanitize_values(test_cases_json: Any, type_map: Dict) -> Any:
        """
        Fix C literal suffixes and values deterministically.

        Checks:
        - Strip struct fields not in type_map struct_fields
        - Add missing struct fields with zero values
        - Fix missing u suffix on unsigned int values
        - Fix missing f suffix on float values
        - Replace NULL with NULL_PTR
        - Replace false/true with FALSE/TRUE for BOOL types

        Args:
            test_cases_json: Parsed JSON from Stage 3A (dict with 'test_cases' list)
            type_map: Parsed JSON from Stage 1B (dict with 'functions' key)

        Returns:
            Updated test_cases_json with corrected values
        """
    ```

    Implementation rules:
    - Accept test_cases_json as either dict or string
    - For each test_case in test_cases list:
      - Get function's param types from type_map → functions → function_name → params
      - For each input param:
        - If param type is a struct (struct_fields present): 
          - Remove any field in inputs[param] that is NOT in type_map struct_fields for that param → log WARNING
          - Add any missing field from struct_fields with zero value (0u for uint, 0 for int, 0.0f for float, FALSE for bool)
        - If param value is a string containing "NULL" (case-sensitive, not NULL_PTR) → replace with "NULL_PTR"
        - If param value is "false" or "true" (lowercase) and param type is BOOL → replace with "FALSE" or "TRUE"
        - If param type has c_type ending with uint/int patterns AND value is a numeric string without 'u' suffix → add 'u'
          - Regex: if value matches `r'^\d+$'` and type is unsigned → append 'u'
        - If param type has c_type containing 'float' or 'float32' AND value is a float string without 'f' suffix → add 'f'
          - Regex: if value matches `r'^\d+\.\d+$'` and type is float → append 'f'
    - Also sanitize expected_return:
      - If expected_return contains "NULL" → replace with "NULL_PTR"
      - If expected_return contains "false" or "true" → replace with "FALSE"/"TRUE"
      - Reject vague values: if expected_return.lower() in {'depends', 'varies', 'unknown', 'tbd'} → set to "E_NOT_OK" and log WARNING
    - Also sanitize expected_output_params values with same rules
    - Log each correction at INFO level
    - Return the modified test_cases_json dict
