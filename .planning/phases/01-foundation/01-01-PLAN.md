2. Define DiffChunk dataclass with fields:
   - chunk_id: int
   - start_line: int
   - end_line: int
   - content: str
   - function_names: List[str]

3. Define DiffValidator class with:
   - __init__(self, max_lines: int = 300): store max_lines
   - Compiled regex patterns as class attributes:
     * DIFF_HEADER_RE: r'^diff --git a/(.+) b/(.+)$'
     * HUNK_HEADER_RE: r'^@@ -\d+(?:,\d+)? \+(\d+)(?:,\d+)? @@'
     * FUNCTION_DEF_RE: r'^(?P<return_type>\w[\w\s*]+?)\s+(?P<name>\w+)\s*\('

4. validate(self, diff_text: str) -> None:
   - Raise ValueError if diff_text is empty or whitespace-only
   - Raise ValueError if no "diff --git" header found
   - Raise ValueError if no "@@" hunk headers found
   - Check for C code indicators (.c/.h files, #include, int\s+\w+, void\s+\w+\()
   - Raise ValueError if no C indicators found

5. chunk_by_function(self, diff_text: str) -> List[DiffChunk]:
   - Split diff into lines
   - If <= max_lines: return single DiffChunk with all lines
   - For > max_lines: iterate lines, accumulate in current_chunk_lines
   - Detect function definitions using FUNCTION_DEF_RE
   - When line count >= max_lines AND at function boundary: split chunk
   - Create DiffChunk with chunk_id, start_line, end_line, content, function_names
   - Reset accumulator and continue
   - Return final chunk if any remaining lines

Do NOT reuse legacy signature_extractor.py — this is a fresh implementation per decision D-01.
